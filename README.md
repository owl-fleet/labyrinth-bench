# LabyrinthBench

A benchmark for measuring context management and look-discipline in LLM agents:
models navigate a procedurally-minted labyrinth where the only objective is the exit,
and the instrument records how they gather, retain, and act on what they observe.

**Release in preparation.** This repository is being staged for public release;
the full README, methodology write-up, and leaderboard will land with the debut.

- Engine + instance mint: `engine/`, `cli/mint_instances.py`
- Evaluation harness: `cli/`, `api/`
- DEG manifests: `degs/`
- First data artifacts: `results/e1a-table1/`
